    Options:
    - Build a VRT mosaic
    - Build pyramids (all levels)
    - Merge the tiles into a single raster
    - Convert to GeoTIFF, ASCII Grid (.asc) or ESRI Float (.flt)

    Also adds a Processing Toolbox algorithm (LiDAR Fetcher UK > Convert raster to FLT / ASC / GeoTIFF) that converts any raster, with batch support.

    Coverage is England only (Environment Agency data).
